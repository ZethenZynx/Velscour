# Campaign and Endgame Environment Schedule

Campaign ranges are fixed and inclusive. `src/data/biomes.js` is the runtime source of truth.

| Depths | Environment |
|---:|---|
| 1–6 | The Forsaken Wilds |
| 7–12 | The Dark Forest |
| 13–18 | Castle |
| 19–24 | Castle Keep |
| 25–30 | Sea of Sand |
| 31–36 | The Great Hunt |
| 37–42 | The Serpentine Tower |
| 43–48 | The Pyramid of the Scorpion King |
| 49–54 | Mountainside |
| 55–60 | Depth's Edge Caverns |
| 61–66 | The Snowy Summit |
| 67–72 | The Endless Siege |
| 73–79 | The Pirate Seas |
| 80–84 | The Sky Lanes |
| 85–92 | The Iron Express |
| 93–99 | The Deep Rail Mines |
| 100 only | Velscour's Throne and the campaign finale |

Campaign boss milestones occur every five depths. Act finales are Depth 25 (Ossuarch, the Bone Colossus), Depth 50
(Pharaoh Sekhmun), Depth 75 (Hollowmere), and Depth 100 (Velscour). The other milestones use the existing named
superboss roster. Depth 100 is the only normal campaign route to Velscour's Throne.

At Depth 101, the infinite endgame opens a randomized pool containing eligible ordinary dungeon environments and
excluding every scheduled campaign environment. It does not apply the campaign's every-five-depth boss-room cadence;
each dungeon retains its existing guardian and completion flow.
